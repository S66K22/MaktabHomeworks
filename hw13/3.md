# 📌 1️⃣ Imbalanced Data چیست؟

**داده نامتوازن** وقتی اتفاق می‌افتد که **تعداد نمونه‌های یک کلاس به شدت بیشتر از کلاس دیگر باشد**.

مثال در طب:

* کلاس 0 = سرطان (Malignant) → 30 نمونه
* کلاس 1 = سالم (Benign) → 300 نمونه

در اینجا نسبت 1:10 است → داده‌ها **شدیداً نامتوازن** هستند.

---

# 📌 2️⃣ چه زمانی این مشکل رخ می‌دهد؟

1. **پدیده‌های نادر**

   * سرطان، تقلب بانکی، خرابی ماشین‌آلات
   * در این موارد، نمونه‌های کلاس مثبت کمیاب هستند

2. **جمع‌آوری داده ناعادلانه**

   * داده‌ها از منابع مختلف یا با روش‌های نامتوازن جمع‌آوری شده‌اند

3. **خطای انسانی یا محدودیت منابع**

   * بعضی نمونه‌ها ثبت نمی‌شوند یا قابل مشاهده نیستند

4. **طبیعت مسئله**

   * بعضی کلاس‌ها طبیعتاً کمتر رخ می‌دهند

---

# 📌 3️⃣ اثر داده نامتوازن روی مدل‌ها

* مدل تمایل دارد کلاس **اکثریت** را پیش‌بینی کند
* دقت کلی (Accuracy) ممکن است بالا باشد، حتی اگر مدل **کلاس اقلیت را اصلاً تشخیص ندهد**

مثال:

| کلاس      | تعداد | پیش‌بینی مدل |
| --------- | ----- | ------------ |
| Malignant | 30    | 0            |
| Benign    | 300   | 300          |

* Accuracy = 300/330 ≈ 91% ✅
* ولی Recall برای سرطان = 0 ❌

> نتیجه: Accuracy گمراه‌کننده است

---

# 📌 4️⃣ روش‌های مقابله با Imbalance

### 🔹 1️⃣ Oversampling (افزایش کلاس اقلیت)

* نمونه‌های کلاس کم را افزایش می‌دهیم
* روش‌ها:

  * **Random Oversampling** → نمونه‌ها را تکرار می‌کند
  * **SMOTE (Synthetic Minority Over-sampling Technique)** → نمونه‌های مصنوعی تولید می‌کند

```python
from imblearn.over_sampling import SMOTE

smote = SMOTE(random_state=42)
X_res, y_res = smote.fit_resample(X_train, y_train)
```

---

### 🔹 2️⃣ Undersampling (کاهش کلاس اکثریت)

* نمونه‌های کلاس اکثریت کاهش می‌یابند
* مزیت: سرعت آموزش سریع‌تر
* معایب: از دست رفتن اطلاعات

```python
from imblearn.under_sampling import RandomUnderSampler

rus = RandomUnderSampler(random_state=42)
X_res, y_res = rus.fit_resample(X_train, y_train)
```

---

### 🔹 3️⃣ ترکیبی (Hybrid Sampling)

* ترکیب Oversampling و Undersampling
* مثال: **SMOTE + Tomek Links**

---

### 🔹 4️⃣ استفاده از وزن‌دهی مدل (Class Weights)

* بیشتر در الگوریتم‌های مثل **Random Forest، Logistic Regression، SVM**
* کلاس کم وزن بیشتری می‌گیرد → خطای آن مهم‌تر محسوب می‌شود

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(class_weight={0:10, 1:1})
rf.fit(X_train, y_train)
```

* یا `class_weight='balanced'` برای تنظیم خودکار

---

### 🔹 5️⃣ تغییر معیار ارزیابی

* به جای Accuracy، از معیارهای حساس به imbalance استفاده می‌کنیم:

  * **Recall (حساسیت)**
  * **Precision**
  * **F1-score**
  * **Balanced Accuracy**
  * **ROC-AUC / PR-AUC**

---

### 🔹 6️⃣ الگوریتم‌های خاص برای Imbalanced Data

* **Balanced Random Forest**
* **EasyEnsemble / BalancedBagging**
* الگوریتم‌هایی که به طور خاص نمونه اقلیت را وزن‌دهی می‌کنند

---

# 📌 5️⃣ جمع‌بندی

| مشکل           | توضیح                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------- |
| داده نامتوازن  | کلاس‌ها تعداد متفاوت دارند (مثلاً 30:300)                                                         |
| اثر            | مدل کلاس اقلیت را پیش‌بینی نمی‌کند، Accuracy گمراه‌کننده                                          |
| روش‌های مقابله | Oversampling, Undersampling, Hybrid, Class Weighting, الگوریتم‌های خاص، استفاده از معیارهای مناسب |

---

💡 نکته مهم:

* در مسائل پزشکی، مثل تشخیص سرطان، **Recall کلاس کم اهمیت بالایی دارد** → اغلب از SMOTE + Random Forest + Balanced Metrics استفاده می‌شود.
